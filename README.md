# qqwry.ipdb (纯真 IP 库 ipdb 格式)

由纯真社区版 CZDB 自动转换，每日检查更新。无需 key 即可查询。

## 文件

- `qqwry.ipdb` — IPIP.net 格式，支持 IPv4/IPv6，字段: 国家/省/市/运营商

## 数据日期

2026-08-22

## 使用

任何支持 [IPIP.net IPDB 格式](https://www.ipip.net/support/code.html) 的解析库均可直接加载。

CDN 加速下载:
```
https://cdn.jsdelivr.net/gh/zzh-blue/ipadd@latest/qqwry.ipdb
```
